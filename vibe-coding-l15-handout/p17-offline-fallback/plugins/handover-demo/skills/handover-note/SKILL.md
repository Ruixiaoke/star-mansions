# 交接说明四格

给一个要交出去的东西写交接说明时，这四格必须都有内容。

## 1. 它会碰什么

列出这个东西能写、能改、能删的地方。只读的不用列。

## 2. 它什么时候会自己跑

它是只在人触发时动，还是会在无人看着时自己动。
会自己动的，写清楚触发条件。

## 3. 它依赖什么外部凭据

包交得出去，钥匙交不出去。列出接收方需要自己准备哪几把钥匙。

## 4. 它坏了之后谁修

写一个角色，或者写「暂时没人，这是已知缺口」。

**不许写「我」** —— 因为作者总有一天不在。
