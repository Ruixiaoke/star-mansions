## 前置

动手前先读：[`CLAUDE.md`](../../../CLAUDE.md) §0 铁律（尤其 §0-2 不臆造、§0-3 隐私、§0-5 素材合规）、§1 技术栈（新增依赖需理由）、§5 交付纪律、§8 部署纪律（环境变量归属）。

本 Skill 只做一件事：**把外部对象查清楚 → 落成一张可查证的卡片**。它不负责实现功能；查完回到原任务再写代码。

## 步骤

1. **先查缓存，别一上来就联网。** 读 [`docs/external/INDEX.md`](../../../docs/external/INDEX.md)。
   若已有对应卡片、**版本匹配**、且**抓取日期在 90 天内** → 直接读该卡片，不联网，跳到第 6 步。
   （版本不匹配或超 90 天 = 过期，按下面继续。）
2. **缺失或过期 → 联网查官方文档。** WebSearch 找入口 + WebFetch 抓正文。
   优先级：**官网 / 官方仓库 README / 官方 API reference** 优先；博客、二手教程只作补充，且必须在卡片里标明来源等级。
   **用户已经给了 URL → 只抓这个 URL（及其官方站内子页），不再 WebSearch 撒网。**
3. **判定类型选模板**：依赖 / API / MCP / CLI → [`templates/DEPENDENCY.md`](./templates/DEPENDENCY.md)；数据源 → [`templates/DATA.md`](./templates/DATA.md)。
4. **按模板填写，落盘** 到 `docs/external/<kebab-case-名称>.md`。**一个外部对象一个文件，不合并写。**
5. **更新索引**：在 `docs/external/INDEX.md` 表格加/改一行（名称 | 类型 | 版本 | 抓取日期 | 置信度 | 链接）；若 `docs/INDEX.md` 与 `docs/README.md` 还没有指向 `docs/external/` 的行，各补一行。
6. **回到原任务。** 编码时**只依据卡片里标为「已验证」的内容**；标「部分验证 / 未验证」的部分不得直接照抄进代码，先按下面纪律回报。

## ⚠️ 查不到时怎么办（本 Skill 的核心纪律）

搜索无结果 / 抓取失败（404、付费墙、需登录、站点拒绝）/ 只找到互相矛盾的二手信息时：

- **不写卡片正文，不猜、不补全、不用「一般来说这个 API 长这样」的记忆凑数。**
- **一律停下来如实回报用户**，报告里必须包含：
  1. 试过的检索词与访问过的 URL；
  2. 失败原因（无结果 / 403 / 付费墙 / 内容与目标版本不符…）；
  3. 目前掌握到的是什么、缺的是什么；
  4. 下一步选项：① 用户提供官方文档链接或内部资料 ② 走下面的**本地兜底** ③ 暂缓，先不写这段代码。
- **不得因为「查不到」就跳过而直接编码**，也不得把没查到的部分静默略过。
- **部分查到时**：写已验证的部分，缺的字段显式写「未知 —— 未找到出处」，禁止用推测填空。
- 卡片顶部的**置信度**必须诚实标注（已验证 / 部分验证 / 未验证 —— 待补），**宁可标未验证**。
- **模型自身记忆不算来源**，禁止把回忆写进「来源清单」；如确需先用记忆做临时假设，须在**卡片和回话里同时**标「⚠️ 未经查证的假设」。

## 本地兜底（允许，但要标清来源等级）

联网查不到时，可退而求其次读**本地真实产物**。这不算编造，但来源要写明**不是官方文档**：

| 类型 | 可读的本地真实产物 |
|------|-------------------|
| npm 依赖 | `node_modules/<pkg>/README.md`、`package.json`、`*.d.ts` 类型声明 |
| CLI | `<cmd> --help` / `--version` 的**真实输出**（把输出贴进卡片） |
| MCP | server 返回的 tool schema |
| 数据源 | 真实样本文件的前若干行 + 实际字段 |

## 来源等级（卡片里每条关键结论都要标）

`官方文档` > `官方仓库产物 / 本地类型声明` > `二手资料` > `未验证假设`

## 铁律

- **不臆造**（CLAUDE.md §0-2）：只写能查证的内容，**禁止编造 API 签名、参数名、返回结构、字段含义**。
- **必留出处**：每条关键结论标来源 URL + 抓取日期 + 版本号。抓取日期用 `date +%F` 的**真实输出**，不凭记忆写。
- **不写密钥**（CLAUDE.md §0-3）：只记录环境变量**名**与获取途径，**绝不**把 key / token / 连接串写进文档。
- **新增 npm 依赖**须在卡片里写「为什么需要它 / 有无更轻替代」（CLAUDE.md §1）。
- **数据源**须填授权与许可（§0-5 可否商用）与隐私分级（§0-3 是否含 PII）。
- 卡片是**给模型查的速查表**，不是教程搬运：只留能直接照抄的**最小可用示例**与**坑**，控制在**两屏内**。
- 卡片改动走 PR，套 `.github/pull_request_template.md`，等 Rick review，不自合并（CLAUDE.md §5）。
